title: Soporte
---

[Abre los formularios de AgentKit](https://github.com/YoshuGH/AgentKit-Docs/issues/new/choose) y elige **Bug report** para reportar un error o **Feature request** para pedir una función. Los reportes son públicos. Elimina las credenciales, los nombres de recursos privados y otros datos sensibles de las instrucciones, los registros y las capturas.

## Reportar un error

Incluye las versiones de Unreal Engine y AgentKit, el cliente MCP o agente que usaste y la instrucción o los pasos para reproducir el problema. Describe qué esperabas y qué ocurrió. Si puedes, agrega el fragmento relevante del Output Log de Unreal Editor.

## Solicitar una función

Describe la tarea que quieres completar en el editor y dónde se queda corto el flujo actual. Incluye una instrucción de ejemplo, el resultado que esperas y cualquier solución provisional que uses.
