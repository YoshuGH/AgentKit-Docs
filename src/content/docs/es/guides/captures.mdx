---
title: Capturas
---

Usa las capturas para revisar cómo se renderiza un Widget Blueprint, comparar poses de una animación UMG o mostrarle la ventana de Unreal Editor a tu agente. Las capturas requieren una sesión del editor con renderizado habilitado.

> Captura `WBP_InventoryHeader` a 640 por 120 con escala DPI de 1. Muéstrame la imagen y dime si el título o el contador de objetos se recorta.

1. El agente usa `CaptureWidget` para renderizar el widget compilado fuera de pantalla. AgentKit guarda el PNG en `Saved/AgentKit/Captures` dentro del proyecto.
2. El agente abre el archivo o usa `agentkit_view_image` para obtener la imagen por MCP.
3. Revisa el texto renderizado y te comparte el PNG o su ubicación.

Obtienes una imagen de 640 × 120 que puedes revisar sin iniciar el juego. Para ver una cuadrícula de poses de una animación, pide `CaptureAnimation`. Para capturar la ventana principal del editor, pide `CaptureSlate` y deja la ventana sin minimizar.
