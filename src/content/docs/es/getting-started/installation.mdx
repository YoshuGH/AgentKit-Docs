---
title: Instalación
---

1. Busca AgentKit en Fab e instala el plugin para Unreal Engine 5.8. La página de Fab estará disponible pronto.
2. Abre tu proyecto o reinicia Unreal Editor si ya estaba abierto. AgentKit se habilita de forma predeterminada.
3. [Conecta tu cliente MCP](../connect-mcp/) y confirma que puede ver los conjuntos de herramientas de AgentKit.
