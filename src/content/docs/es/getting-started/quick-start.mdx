---
title: Inicio rápido
---

Una vez que el editor esté [conectado a tu cliente MCP](../connect-mcp/), prueba con un widget sencillo en una ruta nueva.

> En un Widget Blueprint nuevo llamado `WBP_Status` dentro de `/Game/AgentKitDemo`, agrega una etiqueta centrada que diga «Listo». Usa AgentKit, revisa si hay advertencias de compilación y captura el widget a 400 por 200.

1. El agente crea, compila y guarda el Widget Blueprint con `build_widget`.
2. Ejecuta `validate_assets` e informa si hay diagnósticos.
3. Usa `CaptureWidget` para renderizar un PNG y comparte la imagen o su ubicación.

Abre `WBP_Status` en el diseñador de UMG para revisar el resultado. Consulta la [guía de widgets](../../guides/widgets/) para crear un diseño con varios elementos.
