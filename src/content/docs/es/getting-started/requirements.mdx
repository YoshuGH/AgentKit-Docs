---
title: Requisitos
---

- Un proyecto en Unreal Engine 5.8.
- Un cliente MCP para tu agente que pueda conectarse al servidor MCP de Unreal Editor.
- Una sesión del editor con renderizado habilitado para las capturas PNG.

AgentKit 0.1.0 está en beta. El plugin declara dependencias de ToolsetRegistry, EditorToolset, UMGToolSet, PythonScriptPlugin, SequencerScripting, ModelContextProtocol, SlateInspectorToolset, ModelViewViewModel y MVVMToolset. Unreal las habilita junto con AgentKit.

Varias de las herramientas de Unreal que usa AgentKit son experimentales en UE 5.8.
