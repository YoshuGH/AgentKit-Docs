title: Support
---

[Open the AgentKit issue forms](https://github.com/YoshuGH/AgentKit-Docs/issues/new/choose) and pick **Bug report** or **Feature request**. Issues are public. Remove credentials, private asset names, and other sensitive details from prompts, logs, and screenshots.

## Report a bug

Include your Unreal Engine and AgentKit versions, the MCP client or agent you used, and the prompt or steps that reproduce the problem. Describe what you expected and what happened. Add the relevant Unreal Editor Output Log excerpt if available.

## Request a feature

Describe the editor task you want to complete and where the current workflow falls short. Include an example prompt, the result you want, and any workaround you use.
