## 0.1.0 (beta)

First public release for Unreal Engine 5.8.

- Create, update, and inspect UMG Widget Blueprints and regular Blueprints.
- Build and inspect UMG animations, sample their timing, and compare edits against the last AgentKit build.
- Inspect MVVM bindings and change how an existing viewmodel is created.
- Capture widgets, animation poses, and editor UI as PNGs. View captures through MCP.
- Validate asset loading and report Blueprint compiler diagnostics.
