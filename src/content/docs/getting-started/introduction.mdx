---
title: Introduction
---

AgentKit is an editor-only plugin for Unreal Engine 5.8. It extends what AI agents can do through Unreal Editor's Model Context Protocol (MCP) server. Your agent can build and inspect UMG widgets, regular Blueprints, widget animations, and MVVM configuration. It can also check assets for compiler diagnostics and capture UI as PNGs.

The tools work with standard Unreal assets. Open the result in the editor to review and continue editing it.

Start with the [requirements](../requirements/), then [install AgentKit from Fab](../installation/).
