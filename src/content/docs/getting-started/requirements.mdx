---
title: Requirements
---

- An Unreal Engine 5.8 editor project.
- An MCP client for your agent that can connect to Unreal Editor's MCP server.
- A rendering-enabled editor session for PNG captures.

AgentKit 0.1.0 is a beta. The plugin declares dependencies on Unreal's ToolsetRegistry, EditorToolset, UMGToolSet, PythonScriptPlugin, SequencerScripting, ModelContextProtocol, SlateInspectorToolset, ModelViewViewModel, and MVVMToolset. Unreal enables them with AgentKit.

Several Unreal toolsets AgentKit uses are experimental in UE 5.8.
