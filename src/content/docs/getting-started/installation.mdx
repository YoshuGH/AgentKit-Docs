title: Installation
---

1. Find AgentKit on Fab and install the plugin for Unreal Engine 5.8. The Fab listing is coming soon.
2. Open your project, or restart Unreal Editor if it was already open. AgentKit is enabled by default.
3. [Connect your MCP client](../connect-mcp/) and confirm it can see AgentKit's toolsets.
