---
title: Connect an MCP client
---

AgentKit does not run a server of its own. It adds its toolsets to the Unreal Editor's built-in Model Context Protocol (MCP) server, so any client connected to that server can use them.

1. Open your project in Unreal Editor.
2. Follow Epic's official guide, [Unreal MCP in Unreal Editor](https://dev.epicgames.com/documentation/unreal-engine/unreal-mcp-in-unreal-editor?application_version=5.8), to start the editor's MCP server and connect your MCP client. AgentKit already enables the engine plugins it depends on. To start the server with the editor, enable **Auto Start Server** in **Editor Preferences → Plugins → Model Context Protocol**.
3. Ask your agent, “List the toolsets available in Unreal Editor and tell me which AgentKit toolsets you see.” The agent uses `list_toolsets` for discovery and can use `describe_toolset` to inspect a specific toolset.

If the agent cannot see AgentKit, confirm the editor was restarted after installation, the plugin is enabled, and the MCP server is running.
