# AgentKit Docs

Documentation and support for **AgentKit**, an editor-only Unreal Engine plugin that lets AI agents build, inspect and capture UMG widgets, Blueprints, animations and MVVM through MCP.

- **Documentation:** https://yoshugh.github.io/AgentKit-Docs/
- **Support:** open an issue in [Issues](https://github.com/YoshuGH/AgentKit-Docs/issues/new/choose) to report a bug or request a feature.
